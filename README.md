## Engineering approach

```text
Product idea
    ↓
Scope & architecture
    ↓
Small implementation
    ↓
Regression tests
    ↓
Code review
    ↓
CI
    ↓
Release
    ↓
Measure & iterate
```

I prefer small, reviewable changes over large rewrites.

For important functionality I think about **failure paths, security, concurrency, rollback and regression testing**, not only the happy path.
